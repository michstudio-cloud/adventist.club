Punto de partida al 2026-10-15. Producción: frontend `conquistadores.app` / `admin.adventist.club` / `events.adventist.club` (Vercel), API `api.adventist.club` (Render), Neon con migraciones **001–030** aplicadas. Leyenda: 🙋 lo decide o lo hace el propietario · 🔧 lo hace el equipo (agentes) · ⏳ al final del sprint.

## Objetivo del sprint

Dejar la plataforma lista para que un club real de Conquistadores o Aventureros la use de punta a punta (registro → club → especialidad → evidencia → revisión → certificado), con la operación básica asegurada, y cerrar con la auditoría de seguridad.
